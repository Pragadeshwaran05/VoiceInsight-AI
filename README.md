# 🎙️ VoiceInsight AI

### Intelligent Text & Speech Analysis Platform

VoiceInsight AI is an AI-powered Text and Speech Analysis platform designed to understand written and spoken communication.

The platform combines Natural Language Processing (NLP) and Speech Recognition to transform text and voice into meaningful communication insights.

---

## 🚀 Features

### 📝 Text Analysis

Analyze written content using AI-powered NLP.

- Sentiment Analysis
- Sentiment Confidence
- Word Count
- Sentence Count
- Average Sentence Length
- Keyword Extraction
- Communication Score

### 🎤 Speech Analysis

Analyze spoken communication by processing uploaded audio.

- Speech-to-Text
- Transcript Generation
- Speech Analysis
- Communication Insights
